# 四科导学与实验

## 使用方式

在本地完整版首页点击“四科导学与实验”，或打开 `/academy/?local=1`。公开版使用相同的阅读、实验和课程文件；首次打开公开页面需要联网，不需要模型密钥或账号。

| 科目 | 学习路径 | 自测 | 实验 |
| --- | --- | --- | --- |
| 计算机网络 | 原完整课程 24 课，微课堂 12 课 | 72 + 120 题 | 子网、网关、DNS、静态路由、迁移挑战 |
| 操作系统 | 核心导学 8 节 | 32 题 | FCFS / RR 时间线、就绪队列与时间指标 |
| 计算机组成原理 | 核心导学 8 节 | 32 题 | 直接映射 Cache、地址拆分与冲突 |
| 数据结构 | 核心导学 8 节 | 32 题 | 取模散列、线性探测与满表终止 |

共 60 节课时、288 道自测。新课每节含三个知识点、分步例题、类比、易错点和四道选择题。新课定位为核心导学，不是指定教材全文或考试大纲。

## 一次实验怎么做

1. 读清楚模型范围，检查输入并写下预测。
2. 单步执行或自动播放。网络实验先选诊断工具，修改配置后再次验证。
3. 记录支持判断的证据；必要时逐层查看提示。
4. 完成观察后填写复盘，下载 Markdown 报告或过程 JSON。
5. 换一个变式，重新作出预测。种子、模型版本与参数保留在记录中，可复现同一过程。

网络模型检查请求和回复路径，不修改电脑网络，也不对真实主机发包。调度模型为单 CPU、无 I/O 阻塞、忽略切换开销；同刻到达按输入顺序，片末到达先入队，再让未完成任务回队。Cache 使用 16 位字节地址、只读直接映射，初始所有行无效。散列表仅含插入与查找，没有删除，最多检查表长个位置。

实验结果只能说明给定教学模型和输入下的行为。记录不自动换算成掌握度，也不等同于开发板、真实系统或网络验收。

## 学习记录在哪里

| 入口 | 课时笔记、作答、完成标记 | 实验过程 |
| --- | --- | --- |
| 本地完整版 `?local=1` | 既有 SQLite 数据库，包含在原 JSON 学习备份中 | 当前浏览器，单独导出 |
| 公开版 | 当前浏览器，可导出 JSON | 当前浏览器，亦可按次导出 JSON / Markdown |

公开版不自动上传学习记录，不提供跨设备同步。实验保留最近 20 次，每次保留最近 200 条操作，并注明截断数量。重要实验请及时下载。浏览器拒绝存储或空间不足时会显示提示，当前会话仍可使用并导出。

课时切换前会保存笔记；多窗口出现版本冲突时保留当前草稿，允许先下载草稿再读取已保存版本。现有课时 ID、旧笔记、作答和备份保持兼容。重新打开课程不会替换用户编辑的章节。

## 内容与来源

新增讲义和题目为原创编写，使用 AI 辅助整理；数值例题采用独立计算检查，实验规则使用固定案例和边界测试。没有复制参考教材的全文、插图或题库，未增加参考材料的再分发授权。

| 内容 | 核对与延伸阅读 |
| --- | --- |
| 操作系统：进程、调度、并发、虚拟内存、文件与设备 | [OSTEP 官方章节索引](https://pages.cs.wisc.edu/~remzi/OSTEP/) |

来源列表用于说明核对范围，不表示这些机构审核、认可或合作开发本项目。技术检查不代替教师逐题评审；发现表达或答案问题可通过仓库 Issue 反馈。

## 开发与复现

课程注册表统一管理四个科目、五条路径和稳定课时 ID。新增课程仍使用 `StudyGuide` 和既有章节、笔记、作答、奖励表，未重建旧数据库。新增 `/api/courses` 目录接口和通用课程目录 / 打开接口，保留旧计网、微课堂接口。

浏览器版通过两个适配器共享阅读组件：本地适配器调用已有 API，公开适配器使用浏览器存档。实验规则是无网络依赖的 JavaScript 模块，界面与测试使用同一规则实现。

```powershell
python scripts/export_academy.py
python -m unittest tests.test_app tests.network_course_check tests.microclass_check tests.academy_check
node --test tests/academy_engines.test.mjs
python -m tests.academy_browser
```

浏览器验收需安装开发依赖和 Playwright Chromium。Windows 已安装 Chrome 时，可设置 `$env:ACADEMY_BROWSER_CHANNEL='chrome'`。测试会使用临时目录、独立数据库和临时本地服务器，不访问真实模型或用户数据库。

公开包从 `dist/academy` 的受控文件清单生成，不复制 API 设置、SQLite、教材上传文件或运行缓存。Sites 的源提交和公开包提交对应，课程包摘要记录在 `build-info.json`。公开部署更新应先运行验证，再从已提交的干净主项目生成发布目录。
