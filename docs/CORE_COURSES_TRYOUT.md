# 自愿试用与反馈模板

本文件用于后续收集真实使用反馈；当前不代表已有试用者或学习效果结果。

## 建议流程

邀请愿意参与的同学，自选匿名代号。说明记录由其自行保存在浏览器中，不要求提交姓名、账号或教材。可选择完成一个本科目实验，再尝试一个改变参数的变式，并自愿分享过程报告或文字反馈。

建议首轮 5 位参与者，每人选 1～3 个实验；允许随时退出，不把完成速度作为成绩。

## 单次反馈

- 日期、版本和匿名代号：
- 已学过的课程和相关基础：
- 选用实验、种子和参数：
- 开始前的预测及理由：
- 初次任务是否完成，使用了几层提示：
- 变式是否能独立完成：
- 哪一步不清楚、哪一条提示有帮助：
- 是否发现讲解、答案或模拟结果有误：
- 最希望改进的一项功能：
- 是否同意以匿名方式在项目文档引用本次反馈：

## 汇总口径

只报告实际参与人数和有效任务数量。首次修复比例、提示次数、耗时和变式完成情况分别统计；保留未完成及退出情况。样本小且无对照时，只能作为可用性与改进线索，不得据此宣称普遍提升学习成绩。

将反馈转成明确 Issue：复现步骤、预期结果、实际结果、课程 / 实验版本。修复后记录验证方法与结果，不补造用户反馈或性能数字。
