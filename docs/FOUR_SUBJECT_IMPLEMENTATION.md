# 四科课程与实验实现记录

目标：在保留现有计网、微课堂、笔记、作答和备份的基础上，加入操作系统、计组、数据结构各 8 节核心导学，并提供四科可验证实验。公开版不依赖 AI 或账号，本地完整版保留原有能力。

## 实现顺序

1. 课程内容、统一注册表、兼容接口与推荐。
2. 四类确定性实验与规则测试。
3. 共用课程阅读、实验、存档与导出界面。
4. 回归测试、浏览器和移动端验收、文档与公开部署。

## 根据验收修复的问题

- URL 片段切换实验时，增加路由处理，保证同页跳转更新实际实验。
- 网络已修复后再次改坏配置时，清除旧验证结果并要求重新验证。
- 笔记版本冲突时保留当前草稿，可下载后读取已保存版本。
- 实验单步操作先完成存档再显示新步骤，防止快速刷新少恢复一步；保存期间避免重复推进。
- 本地完整版的严格 CSP 下使用外部样式和受控 DOM 样式更新，实验界面无 CSP 违规。
