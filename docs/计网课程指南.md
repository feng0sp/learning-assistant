# 计算机网络课程指南

这是面向本科通用计算机网络课程的原创精讲版学习工具。它提供从基础到综合实践的学习闭环，不声称复刻所有教材、专业选修课或某个考试大纲。未指定教材时按下表推进；若学校课程顺序不同，可以搜索课时，也可通过「开始新章节」导入自己的资料。

## 课程地图

| 单元 | 课时 | 主要内容 |
| --- | --- | --- |
| 网络基础 | 01–03 | 分层、协议与服务、封装；发送/传播/排队时延与带宽时延积；电路/分组交换和存储转发 |
| 物理层 | 04–05 | 码元、比特、奈奎斯特和香农界限；编码、调制、复用、介质与双工 |
| 数据链路层 | 06–09 | 成帧、透明传输、CRC；停止等待、GBN、SR；交换机、MAC、VLAN；无线接入与隐藏终端 |
| 网络层 | 10–14 | IPv4、CIDR、VLSM；最长前缀、ARP、ICMP、分片；RIP、OSPF、BGP；IPv6；NAT、DHCP |
| 传输层 | 15–18 | 端口与 UDP；TCP 字节流、序号、重传；建连、关闭、TIME_WAIT；流量和拥塞控制 |
| 应用层 | 19–22 | DNS；HTTP、缓存与版本区别；邮件、MIME、文件传输；CDN、媒体缓冲和网络管理 |
| 网络安全 | 23 | 密码工具的职责、TLS、证书、防火墙与 VPN 的保护边界 |
| 综合实践 | 24 | 从打开网页到分层排障、证据记录和授权环境中的观察实验 |

每课包含 3 个重点知识条目、1 道分步例题、1 个注明局限的生活类比、3 道自测。共 72 个知识条目、24 道例题、24 个类比、72 道自测。课程属于精讲，不能替代教材的全部推导、课堂实验或大量习题训练。

## 建议用法

1. 从课程目录推荐的下一未完成课时进入。每课约 25 分钟只是安排参考，可以拆成多次学习。
2. 读概览和知识点，自己用一句话复述关键结论。
3. 先独立做例题，再展开步骤；计算题写清单位和假设。
4. 查看类比中的对应关系，同时阅读“类比的局限”。
5. 完成自测；错误会进入现有的「错题复习」。最近一次答题结果用于目录统计，不能代替长期掌握评估。
6. 写下疑问和计算过程，确认笔记已保存。理解后自行标记已学完。
7. 学完一轮后做两套综合练习，按题目中的课时名返回复习。综合卷复用课内题，提交每题就会展示解析，因此不是独立的闭卷测验，也不提供考试分数预测。

笔记、完成标记、练习结果与综合卷都使用现有本地数据库，可导出 JSON 备份或打印讲义。新版 JSON 备份还会保存积分和每日练习记录，重复合并不会重复加分。浏览器中的“上次阅读课时”是本地浏览偏好，不属于跨电脑备份内容。AI 追问与按资料生成仍需配置模型，课程阅读和计算实验本身不需要模型。

顶部「学习成长」可以直接开始每日练习，优先回到错题，再按课程顺序推荐其他题目。每天答对 3 道不同课程题即可完成小目标，之后可选择继续。每题首次答对奖励 10 分，每课三题全部答对再奖励 20 分；复习不重复发奖，答错不扣已有积分。

## 计算实验室

| 实验 | 输入示例 | 应得到的关键结果 | 适用条件 |
| --- | --- | --- | --- |
| IPv4 子网 | `192.168.1.70/26` | 网络 `.64`，广播 `.127`，主机 `.65–.126`，62 个 | 普通 IPv4 广播子网；另对 /31 点对点与 /32 单地址解释 |
| 时延 | 1500 Byte，10 Mbps，每跳 1000 km，传播速度 2×10⁸ m/s，1 跳 1 包 | 发送 1.2 ms、传播 5 ms、总计 6.2 ms | 等长等速链路；不含处理、排队、重传和头部 |
| 流水线 | 125 Byte，1 Mbps，距离 0，3 跳 4 包 | 6 ms | 等长分组、等速存储转发 |
| CRC | 数据 `1101`，生成式 `1011` | 余数 `001`，发送 `1101001` | 裸模二除法；不含具体 CRC 标准的初值、反射、最终异或 |

实验不会自动探测网络或修改网卡、路由、DNS。计算结果用于解释模型，不是实际吞吐、时延或地址可部署性的承诺。

## 常用公式与边界

- 发送时延：`L/R`，L 用 bit、R 用 bit/s。
- 传播时延：`d/v`，距离和速度单位一致。
- 等速存储转发：`(P+H−1)L/R + H×d/v`，各跳等长，P 为包数，H 为链路数。
- 香农容量：`B log₂(1+S/N)`；dB 先转换为 `10^(dB/10)`。
- 理想无噪声低通信道奈奎斯特界限：`2B log₂M`，明确 M 个可区分信号状态。
- 普通 IPv4 子网通常可用地址：`2^(32−n)−2`；/31、/32 不机械套用。
- 经典 GBN：k 位序号的发送窗口不超过 `2^k−1`；经典等窗口 SR 不超过 `2^(k−1)`。
- TCP 连续收到从 S 开始的 N 字节数据，且无 SYN/FIN：下一期望确认号为 `S+N`。
- 简化 TCP 新增可发量：`max(0,min(rwnd,cwnd)−在途量)`，统一单位，实际还要服从窗口边界与协议状态。

## 延伸阅读与内容定位

TCP 的序号和连接机制参考 [RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)，IPv6 机制参考 [RFC 8200](https://www.rfc-editor.org/rfc/rfc8200.html)，/31 点对点规则见 [RFC 3021](https://www.rfc-editor.org/rfc/rfc3021.html)。DNS、HTTP、TLS 分别可继续阅读 [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034.html)、[RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)、[RFC 8446](https://www.rfc-editor.org/rfc/rfc8446.html)。这些标准可能有后续更新与勘误；本工具讲解其基础机制，不是协议实现的完整合规说明。

讲义和题目为原创总结，没有复制教材原文；“资料来源”显示的是内置讲义片段及相关延伸阅读，不虚构教材页码。程序测试验证数据保存、界面流程、题目结构及计算器数值，不等于专家审定了每一条教学表述。实际考试仍应对照老师的大纲与指定教材。
