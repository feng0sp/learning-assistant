# 网络层入门笔记

这是一份用于试用资料导入的原创示例，不对应某本教材的版次或章节编号。

## 网络层解决什么问题

网络层负责把分组从源主机送到目的主机，可能经过多个互联的网络。IP 分组携带源 IP 地址和目的 IP 地址，路由器利用目的地址选择下一跳。

IP 提供无连接、尽力而为的交付，不保证分组一定到达，也不保证顺序或带宽。需要可靠交付时，需要其他机制提供相应功能。

## 转发和路由选择

转发是单台路由器的局部动作：收到分组后，根据转发表决定输出接口，再把分组送出去。

路由选择负责确定路径并形成或更新路由信息。可以把它理解成决定路线，而转发是在一个路口执行当前的指路规则。这个类比只用于帮助区分职责，不能替代对路由协议的学习。

## IPv4 与地址前缀

IPv4 地址有 32 位。CIDR 写法中的 /n 表示前 n 位是网络前缀。

例如，192.168.10.0/24 的主机部分还有 8 位，总地址数为 2^8 = 256。在传统子网配置下，网络地址 192.168.10.0 和广播地址 192.168.10.255 通常不分配给普通主机，因此通常有 254 个可用主机地址。

这个「总数减 2」的规则有适用范围。/31 点对点链路和 /32 主机路由需要单独理解，不能机械套用。

## 最长前缀匹配

路由器可能发现多条路由都与目的地址匹配。这时优先选择其中前缀最长、覆盖范围最具体的一条。

例子：路由表包含 192.168.0.0/16 → A，192.168.1.0/24 → B，0.0.0.0/0 → C。目的地址为 192.168.1.42 时，三条前缀都匹配，应该使用 /24 路由并选择下一跳 B。

默认路由 /0 用于没有更具体匹配的情况，不代表默认拥有最高优先级。

## TTL

IPv4 分组的 TTL 在路由器转发时递减。TTL 耗尽的分组被丢弃，用于限制分组在网络中的存活，避免无限循环。

TTL 不是网速指标，也不保证分组成功到达目的地。
